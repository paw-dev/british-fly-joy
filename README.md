# Fly&Joy – Multi-Page Travel Agency Website

A responsive travel agency website developed for a UK-based client.  
This is the original version I created using HTML, SCSS, and JavaScript. It was later integrated into WordPress and is currently in use by the client (with further modifications).

## Description

The site consists of three pages:  
- **Home** – includes a dynamic tour slider, category filter, FAQ section, social media links and JavaScript interactivity
- **About us** – displays travel offers using responsive layout   
- **Contact** – contains a contact form for user inquiries

Built using modern layout techniques (**Flexbox** and **Grid**) and basic **JavaScript** for UI interactions.

## Features

- Fully responsive design (mobile, tablet, desktop)  
- Swiper.js slider for tour cards  
- JavaScript-powered filter for tour categories  
- Expandable FAQ section (JS)  
- Social media links  
- Contact form  
- Multi-page structure

## Technologies Used

- HTML5
- SCSS
- CSS3 (Flexbox, Grid)  
- JavaScript  
- Swiper.js

## Notes

This is the original static version of the project, created before the WordPress integration.  
The live version used by the agency has been modified since launch.
